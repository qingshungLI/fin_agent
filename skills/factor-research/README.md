# AURORA Factor Research Skill

Download `SKILL.md` from the AURORA project console or install from GitHub:

```bash
git clone https://github.com/qingshungLI/fin_agent.git
cd fin_agent
pip install -e .
```

The Skill turns user-owned daily panels into auditable RSI alpha research runs. It supports bounded factor expressions, fast exploration, lineage-preserving evolution, validation, cost-aware reports, and local API orchestration.
