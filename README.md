# AutoAlpha Harness

**服务器运行说明见 [SERVER_RUNBOOK.md](SERVER_RUNBOOK.md)，当前验收与未完成项见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。设计目标不代表已取得正式因子结论。**

**一个用证伪压力驱动的自动化因子研究系统。**

它不产出因子排行榜。它产出三样东西：

1. **一本规律账本** `law.md` —— 关于这个数据集本身的知识，例如"短期反转只在小市值成立、沪深300成分股内符号相反"。这类知识不会因为被别人知道就失效。
2. **一批被明确证伪的机制假设** —— 知道什么不成立，与知道什么成立同样有价值，而且它是下一轮研究的输入。
3. **少量经过完整检验的可交易结构** —— 通常只有 1–3 个。

> 相关文档：函数级实现契约见 `PSEUDOCODE.md`（v5）；竞品格局与数学结构见 `NOVELTY.md`。

## 一、数据范围

| 项 | 值 |
|---|---|
| 品种 | A 股，**只有日频量价** |
| 时间 | 2016-07-01 至 2026-07-30，2448 个交易日 |
| 截面 | 5562 只股票（含已退市），日均约 4300 只在池 |
| **没有** | 文本 / 研报 / 分钟频 / 财务报表科目 / 融资融券 / 龙虎榜 / 北向资金 |

**三个别人通常没有的资源**：

- **`num_trades`（成交笔数）** —— `total_turnover / num_trades` 就是平均单笔成交额，参与者结构的直接代理。多数公开因子库没有这一列。
- **`open_auction` 五档盘口** —— 日频数据里罕见地含真实买卖盘口与委托量。它同时支撑整个"隔夜信息聚合"机制族，并让成本模型里的价差**从数据实测**而不是拍一个假设。
- **行业归属精确有效期** —— 使 PIT 行业中性化可以做对。多数团队用月末快照，会有最多一个月的错配。

所有原始数据先经过独立的 `validate_data_sources` 组件。它检查主键、日期、连接行数、单位量级、行情不等式、复权事件、行业有效期和盘口异常；高严重度失败会阻止面板构建。检查报告本身是比赛展示的一部分，未知口径不会被默认填零。

## 二、要解决的问题

### 搜索本身会制造假阳性

自动化因子挖掘（遗传规划、LLM 生成表达式）都遵循同一流程：生成大量候选公式 → 回测 → 挑最好的。

假设你有 10000 个**完全无用**的候选因子。在零假设下，最大的那个 IC 大约会是 $3.9\sigma_{IC}$（10000 个正态样本的期望最大值）。用本项目的真实数字 $\sigma_{IC}\approx 0.014$：

$$\max \text{IC} \approx 3.9 \times 0.014 \approx 0.055$$

**IC = 0.055 会被认为是个不错的因子。而它是从纯噪声里挖出来的。**

更麻烦的是，报出来的 t 值分母里**从来没有算进"我搜了 10000 次"**。所以这类系统论文里的数字总是好看，上线就失效。

### 三个次生问题

| 问题 | 现状 | 本系统 |
|---|---|---|
| 判定只有两态 | "好"或"不好"，没有"数据不足以判断" | **三态**，UNDECIDABLE 是最常见的正确答案 |
| 失败被丢掉 | 只留赢家，每轮从零开始 | 失败进层次模型，是估计族效应与时间效应的样本 |
| 机制只是叙述 | 配一段经济学解释，但它不进任何统计量 | 机制必须推出**编号的可判真假断言**，逐条检验并计入证据 |

## 三、一句话架构

**这是一个遗传算法，但它的选择压力不来自收益，来自证伪。**

```
   种群  ── 机制地图 10×7，52 格可行，事前枚举完毕，完全不碰未来收益
             │
   闸门  ── 这个结构自己的 n_eff 够不够判定？
             不够 → UNDECIDABLE，不花任何证据额度
             │
   测量  ── IC/分组收益曲线、月度分位、分层、贡献集中度、HAC t、
             方向命中率、事件研究、成本敏感性
             ＋ 逐观测影响函数分解 Ψᵢ  ← 发现层的燃料
             │
   选择  ── 四把刀：① 安慰剂 ② 断言 ③ 增量 ④ 确认段上的正交矩检验
             │
   证据  ── e-process 赌本：e 值 = 似然比 = 盲下注的赌本增长
             Ville 不等式保证随时可看、随时可停，I 类错误仍受控
             │
   发现  ── 探索段：先分流「均值误设 vs 方差异质」→ 因果森林出候选（只给变量名）
             ★ 缝：在这里写机制与断言，此时确认段尚未被读取
             确认段：主效应 + 形状 + 旁证，三者同时检验
             │
   演化  ── ① 横向 换表现形式  ② 纵向 加条件（来自发现层）
             ③ 跨行 换机制      ④ 交叉 借条件（GA 的 crossover）
             │
   一致性 ─ 符号图平衡（一个算法六处用）；受挫圈定位缺失的调节变量
             │
   账本  ── law.md：度量 / 传导 / 条件 / 边界 四类规律
             │
   记忆  ── 层次贝叶斯：共享效应识别 + 空白格先验上色 + 设计可辨识性诊断
             → 指定下一个探针 → 回到地图
```

## 四、八个设计决定

### 1. 想法空间是一张 10×7 的矩阵，不是一个表达式空间

**行 = 机制族**（为什么会有超额收益）：注意力冲击 / 流动性提供 / 处置效应与锚定 / 信息缓慢扩散 / **交易约束（A股特有）** / 被动资金与再平衡 / **参与者结构** / 风险补偿与估值 / 不确定性解决 / **隔夜信息聚合**

**列 = 表现形式**（在日频量价里长什么样）：水平 / 变化 / 时序相对 / 截面相对 / **背离** / 条件化 / 事件化

70 格中约 **52 格可行**——这就是想法的**全集**，不是几万个表达式。三个后果：

- **枚举是免费的**（完全不碰未来收益）。"想法空间有多大""探索了多少"成为可以报出的数字。
- **空白格是研究计划**，灰格是推理结论。
- **标签成为统计模型的设计矩阵**，跨研究的记忆才有载体。

**"背离"这一列是本项目特有的设计**：价涨量缩、竞价强而全天弱、大单流入但价格没涨。它天然是**两个变量的关系**而非单一变量的水平，因此更难被简单的线性因子覆盖。

### 2. 每份档案分成两半：标签与断言

```yaml
# 标签：受控词表，构成统计模型的设计矩阵
agent:      liquidity_provider    # 谁的行为产生了这个效应
friction:   inventory_risk        # 他受什么约束
mispricing: temporary_impact      # 产生什么形式的偏离
correction: inventory_unwind      # 谁在什么尺度上纠正它
form:       F3_ts_relative

# 断言：编号的可判真假命题，冻结后永不可改
P1  剂量曲线单调向下
P2  峰值 horizon ∈ [1,5]
P3  效应符号为负
P4  在流动性差的股票上效应更强      ← 旁证，不指向因子本身
P5  在竞价价差宽的股票上效应更强    ← 另一个独立旁证
```

**两者生命周期相反**：标签会被词表归一化重写，断言一旦冻结就不能动。混在一起，归一化时会误伤断言，所有历史赌本失效。

**标签的取值空间受控，断言的取值空间开放。** 你事先想不全该用哪些标签描述一个因子，但总能对某个具体因子写下几条它该满足的命题。想加新的可证伪预测就加一条 `Pn`，**不用改 schema**。

**"旁证"是硬要求**：至少两条，且至少一条不指向因子本身。P3 说的是因子与收益的关系；P4 说的是"如果我的机制对，在**别的地方**也应该看到某个现象"。**只写 P1–P3 的档案等于没有描述任何机制。**

**P2 让 horizon 不再是可调参数**。常规做法是扫 h=1..10 挑 IC 最高的——那是调参。这里机制事先规定"存货出清很快，峰值应在 1–5 天"。实测峰值若在 10 天，**那不是"因子更好了"，是 P2 被证伪**。

### 3. 测量和判别分开，但测量层是接口不是报告

统计面板有二十几个数字，但它们是**同一次测量的不同切片**。高分辨率是好事，但它回答不了"这个效应是不是假的"——你把 IC 切成两百个数，伪影也会被切成两百个数。

所以判别只有四把刀，各自排除一种**不同性质**的错误：

| 刀 | 排除什么 | ✗ 之后 | 用哪段数据 |
|---|---|---|---|
| ① 安慰剂 | 效应是**假的** | 效应**作废**，回数据层 | 探索段 |
| ② 断言 | 效应真，但**原因不是你说的** | 效应**保留**，重写标签、开新 ID | 探索段 |
| ③ 增量 | 真的、原因也对，但**早就有了** | 回退，父层即终点 | 探索段 |
| ④ 正交矩 | 搜索出来的条件其实**不成立** | UNDECIDABLE 或 FAIL | **确认段** |

**刀①和刀②的动作相反**（作废 vs 保留）——这是四把刀绝不能聚合成一个综合分数的根本原因。

反过来，因为刀只输出 pass/fail、几乎不含信息，**测量层就成了系统里唯一的信息来源**。它同时喂四个下游：判别、**发现（逐观测影响函数分解 Ψᵢ 是发现层的唯一燃料）**、档案、组合。所以面板要以数值落盘，不只是出图。

### 4. 三态判定，UNDECIDABLE 是最常见的正确答案

名义面板有 1049 万行，但真实的独立样本量约 **2500–5000**——差三个数量级。原因是同日股票高度相关、且 h 天的标签互相重叠。

有效样本量的唯一正确定义是从数据里**量出来**的：

$$n_{\text{eff}} := 1/\sigma_{IC}^2, \qquad \sigma_{IC} \text{ 由块 bootstrap 估计（块长必须} \ge h)$$

这个数决定了什么算显著（$n_{\text{eff}}=4900 \Rightarrow$ IC 要超过约 0.029 才有 t>2），**因此它必须印在每一张 IC 图的角上**，而且要**逐结构分别算**——一个只覆盖 15% 样本的结构，有效样本量也只有 15%。

于是判定必须是三态：

- **PASS** — 生成结构卡，交给交易层
- **FAIL** — 与断言矛盾。**有信息的失败**，写进账本，触发逻辑修正
- **UNDECIDABLE** — 数据不足以区分。**没信息的失败**，不修改任何逻辑，记下重开条件

把 FAIL 和 UNDECIDABLE 混在一起，你会把"没有证据"当成"有反面证据"，然后去改一个本来没问题的逻辑。

**如果第一版跑完 PASS 超过 5 个，最可能的解释是阈值设松了，不是运气好。**

### 5. 证据用赌本度量

**核心事实**：如果零假设为真，没有任何下注策略能让你的期望财富增长。这是数学定理，不是经验规律。

反过来说：**如果你的钱涨到 20 倍，要么运气极好，要么零假设是错的**——而"运气极好"的概率不超过 5%。

一个 e 值是满足 $\mathbb{E}_{H_0}[e]\le 1$ 的量，赌本 $W=\prod e_i$。由 Ville 不等式：

$$\mathbb{P}_{H_0}\big(\exists n:\ W_n \ge 1/\alpha\big)\le \alpha$$

注意是 **$\exists n$——对所有时刻同时成立**。p 值只在预先设定的时点看一次才有效，边跑边看会让 I 类错误远超 5%；而**研究的真实工作方式就是反复看**。e 值让这件事在数学上合法。

**盲下注就是下注**：LLM 给出概率 $q$，零假设下断言碰巧成立的概率是 $p_0$（从经过验证的安慰剂分布估计）。首版先把它作为 Brier 分数、对数损失和校准曲线的研究指标；`p0` 估计误差和 `untested` 选择规则冻结后，才决定是否把它接入正式 e 值。

$$e = q/p_0 \ (\text{成立}), \qquad e = (1-q)/(1-p_0)\ (\text{不成立})$$

验证：$\mathbb{E}_{H_0}[e] = p_0\cdot\frac{q}{p_0} + (1-p_0)\cdot\frac{1-q}{1-p_0} = 1$。**对任何 $q$ 都成立。**

这一点值得体会：**下注比例完全自由，但公平性是结构性保证的。** LLM 给的概率再离谱也无法凭空制造证据，只能让自己赚得快或赔得快。这正是我们需要的——让它表达信念（那是可解释性的来源），但不让它的信念污染证据。

这些性质只在 e-process 的条件期望约束成立时适用。本项目首版采用冻结候选批次的正式检验和 Holm 全库错误控制；赌本轨迹仍保留，用于研究方法展示和后续验证。

### 6. 进化的方向是发现出来的，不是事先枚举的

不能事先列一张"什么失败对应什么动作"的路由表，那只是把设计者的想象力写死。正确的做法：**方向由数据产生，机制由人写，正当性由另一半数据裁决。**

**① 探索段：先分流，再搜索**

失效点聚集有三种成因，动作完全不同：

| 成因 | 含义 | 动作 |
|---|---|---|
| 均值误设 $E[\Psi\mid Z]\ne 0$ | 在 Z 上系统性偏一边 | **改逻辑**：Z 是缺失的调节变量 |
| 方差异质 $\mathrm{Var}[\Psi\mid Z]$ 大 | 方向没错，只是那里噪声大 | **改仓位**：$w \propto 1/\sigma$，不开新格子 |
| 标签污染 | 那里的收益算得就不对 | **改数据层**，这一格作废 |

**第二种是绝大多数人踩的坑。** 失效点必然扎堆在高波动区，因为那里方差本来就大。在那里加一个门，不是发现了市场状态，只是剔掉了噪声大的样本——样本内必然变好，样本外必然崩。**而且分样本挡不住它**（两段的方差结构一样），所以这一步必须在搜索之前。

**② 缝：在这里写机制，此时确认段还没被读**

森林给的是一个**变量名**，不是一个机制。所以流程必须在这里停下来，补出完整的标签与断言——包括"这个变量在高区应该是什么方向"。

**这条纪律有一个物理位置去执行**：确认段独立目录 + 读取审计锁 + 哈希链，不靠自觉。

**③ 确认段：同时检验三样**

主效应（单点正交矩检验）、形状是否符合断言、**旁证断言是否出现**。只过第一条得到的是"这里效应更强"；三条都过得到的才是"这里效应更强**且原因是我说的那个**"。这一步把"找到一个变量"变成了"检验一个机制"。

搜索的代价由**丢掉探索段**支付，所以确认段做的是普通单点检验，用标准临界值，不必再付 sup 临界值那笔钱。

### 7. 一致性检查：一个算法，六个用处

把论断的实例连成图，边的符号表示两个实例是否一致，则：

> **可以一致地拼起来 ⟺ 符号图平衡 ⟺ 不存在含奇数条负边的圈**（Harary）

O(V+E) 可算，而"语境"可以是六种不同的东西：

| 用处 | 节点 | 受挫意味着 |
|---|---|---|
| 组合 | 已通过的结构 | 缺一个调节变量，**圈上结构的覆盖交集就是它起作用的区域** |
| 收敛效度 | 一个机制的三个表达式 | 机制没被正确表达 |
| **状态发现** | (结构, 时间块) | 存在市场状态结构 |
| **词表诊断** | 共享同一标签的结构 | 这个标签是多义的，该拆 |
| **账本自洽** | law.md 条目 | 账本内部自相矛盾 |
| 跨市场 | 同一机制的不同市场实例 | 机制不普适（v2 议题） |

三点值得说明：

- **状态发现把顺序倒了过来**：不是先挑一个状态变量再切分，而是先用二分找出哪些时间块属于同一组，**再回头找什么变量能分开这两组**——先发现存在性，后命名。这给发现层提供了一个与因果森林完全独立的入口。
- **词表诊断降低架构的单点风险**：层次模型是全项目风险最高的部件，而"某标签下的结构彼此矛盾就该拆"这个判断**不需要贝叶斯**。
- **账本自洽通常没人做**：law.md 越写越长而无人检查条目之间是否矛盾。配上受挫指数按时间画成曲线，就是"这套知识体系的内部一致性随研究推进的变化"。

### 8. 记忆层：跨研究的信息共享，以及一个必须承认的限制

层次模型把"跑过的研究"变成"接下来研究什么"的输入：

$$\hat\tau[s,t] \sim N(\tau[s,t],\ \hat\sigma^2[s,t]), \qquad \tau[s,t] = \mu + a_{\text{family}} + a_{\text{form}} + b_t + u_s$$

它**不打分、不排序、不判定**，只做三件事：识别跨结构共享的效应（全库在某段时间一起变化 = 一条规律，不是十个因子各自失效）；给未研究的格子合成先验（**整张地图在跑数之前就能上色**）；诊断哪些因子在数学上不可分离。

最后一项的意义特别大：**它会告诉你，问题不在某个因子里，在你选格子的方式里。**

**必须承认的限制**：`agent` 与 `friction` 在机制上捆绑——散户总配注意力带宽，做市商总配存货风险，你写不出既合法又有意义的交叉组合。**所以这两个效应在原理上就不可分离，没有任何实验设计能解决。** 处理方式是承认它：四个机制槽位在统计模型里**折叠成一个 family 因子**，设计矩阵是 10×7 两因子而非五因子。五槽位仍留在档案里（给人和 LLM 读，也是词表一致性检查的输入）。

因此冷启动的目标不是"挑最可能成功的格子"，而是**让设计矩阵可辨识**：一个标准 2×2 析因（M1/M2 族 × 水平/时序相对形式），四个观测恰好估出截距、两个主效应、一个交互，一个不多一个不少。**随便挑四个最看好的格子，它们标签互不相同，什么参数也估不出来。**

## 五、LLM 的五个岗位

**按能看到什么信息划分，不按能力划分。**

> 总原则：**看到收益数据之前岗位无限；看到之后只剩一个岗位，且那个岗位不许写因果句。**

| 岗位 | 能看到 | 绝对看不到 |
|---|---|---|
| **提案器** | 候选变量的**名字**、词表、账本、地图、血缘 | **任何效应读数** |
| **算子化器** | 标签 + 可用字段 | 收益 |
| **盲下注器** | **只有标签和断言** | 一切数据 |
| **对账员** | 全部数据 | —（但**禁止写因果句**） |
| **归纳器** | 账本 + 后验系数 | 原始收益 |

**第一行那条边界是整个发现流程的意义所在。** 如果告诉提案器"这个变量在高区效应更强"，它写出来的断言必然是"效应在高区更强"——**这条断言只是复述了观测，没有任何证伪力**。只给变量名，它必须从机制推出方向，断言才有可能是错的。**而能不能错，是它有没有信息的唯一标准。**

对账员那条约束也不是洁癖：防火墙不是防它撒谎，是**防它诚实地做一件不该做的事**——看过收益之后写出的因果句，形式上和事前写的一模一样，性质完全不同。

### 为什么防火墙必须由结构强制

2026 年一项跨八个科学领域、两万五千余次 AI agent 运行的评估发现：**证据在 68% 的轨迹中被忽略，由反驳驱动的信念修正只发生在 26% 的情况下。**

结论很直接：**不能指望 LLM 在被证伪时自己修正信念。** 所以"不许偷看"不是一条提示词，而是四样工程措施：确认段独立目录 + 审计锁、内容哈希链、白名单构造上下文、盲下注时间戳早于测量。

### 盲下注：把可解释性变成一个数

一个 LLM 实例只拿到标签和断言，不给任何数据，让它预测每条断言是否成立。**预测先落盘加时间戳，再跑数。**

于是每个结构多一行：**"这份档案让一个没看过数据的读者猜对了 4/6 条。"**

它的意义远超一个指标。设真实成立概率为 $P$、你按信念 $q$ 下注：

$$\mathbb{E}[\log e] = \underbrace{D_{KL}(P\,\|\,p_0)}_{\text{数据里客观有多少证据}} - \underbrace{D_{KL}(P\,\|\,q)}_{\text{你的机制故事错了多少}}$$

**赌本涨得慢有两个可能的原因，而它们在数学上是分开的。** 这也给了可解释性一个严格定义：

> **一条机制陈述可解释，当且仅当按它下注能赚钱。**

这不是比喻，就是上式的第二项。

## 六、产出物

### 1. 规律账本 `law.md`

不是记"哪个因子失败了"，是记"这个数据是什么脾气"：

| 类 | 例 |
|---|---|
| **度量层** | 换手率的截面分布在 2020 年后显著右移，同一个 z 分数在两个时期含义不同 |
| **传导层** | 隔夜跳空的效应在 T+1 开盘一次性释放；盘中形成的动量分散在 T+1 到 T+3 |
| **条件层** | 短期反转只在小市值成立；沪深300成分股内符号相反 |
| **边界层** | 该效应集中在 T+1，固定成本吃掉约六成，容忍度 14bp |

每条五个字段，其中两个是硬要求：

- **`scope_predicate` 必须是可求值表达式**（`market_cap_pct < 30`），否则组合层用不了它。散文式的 scope 只能进报告，不能进路由。
- **`confirmed` 是一道闸门**：未确认的规律**可以指导研究，不能指导仓位**。不设这条，组合会慢慢变成账本里所有观察的叠加，而账本里有一半是还没验的猜测。

关于**自己代码**的发现（前视 bug、复权错误）写进变量注册表备注，**不进账本**——否则账本会被自己的 bug 稀释。账本记的是可以跨项目带走的资产。

### 2. 结构卡 —— 研究层与交易层的唯一接口

| 研究层提供 | 交易层负责 |
|---|---|
| 条件区域（在哪里适用） | 入场触发 |
| 方向 | 出场规则 |
| 有效 horizon | 仓位与杠杆 |
| 失效监控量 | 多结构冲突仲裁 |
| 成本容忍度（bp） | 拆单与滑点控制 |
| 森林入选频率（稳健性） | 容量测算 |

**研究层不给价位，交易层不改逻辑。** 这是防止交易层的调参回流污染研究层的唯一屏障。

**注意成本的处理**：研究层保持 IC 与 TB 的研究口径；交易成本在冻结的参考持仓规则下由回测组件计算。统一扣除固定成本不会改变截面 IC，因此成本容忍度定义为参考策略平均净收益降到零的成本水平，同时报告 Sharpe、收益、换手和成本情景。

回测主口径是股票多头加现金：T 日收盘生成信号，T+1 开盘尝试成交。买入或退出无法成交时直接报错并终止本次回测，不能静默修改持仓记录。多空分组收益只作为 TB 研究指标，不代表可执行做空。

### 3. 因子 —— 地图上的一条覆盖路径

陈述层的产物天生**稀疏且有条件**（某个结构可能只覆盖 15% 的样本），而因子需要稠密。传统做法把稀疏结构稀释成全样本因子，效应立刻被 85% 的噪声摊平——**这是"逻辑很漂亮但做不成因子"的主要死因。**

正确做法反过来：**三个各覆盖 20% 的强结构拼起来，远好于一个覆盖 100% 的弱因子。** 覆盖不到的样本就是空仓，这是诚实的。

于是"把地图填满"不只是研究上的完整性，**它直接就是提高覆盖度的路径**——两件事在这个架构里是同一件事。

**两个必须做对的技术细节**：

- **覆盖外必须是 NaN，不能是 0。** `0` 的语义是"我认为该持平"，`NaN` 是"我没有意见"。三个结构里两个 NaN 一个 +1，等权聚合应该给 +1，不是 +1/3。混淆这两者会系统性稀释稀疏结构的信号。
- **不同 horizon 的结构不能在分数层相加。** 每个结构输出的是**目标持仓路径**，按自己的衰减速度展开，然后在仓位层求和。衰减速度来自档案的 peak horizon 断言与账本的传导层规律——**这就是传导层规律进入组合的具体入口。**

组合层还有一条硬边界：**不许创造新逻辑，只能做路由、加权、执行对齐。** 任何逻辑上的新组合必须回研究层立新格子、走完整套刀。否则你在组合层取个交集，就造出了一个从未通过任何检验、样本量比两个成分都小的新结构，研究层所有纪律从这个后门漏光。

### 4. 档案 —— 每个结构一个文件夹

```
research/S-0001/
  structure.yaml    标签 + 断言 P1..Pn + 三个表达式 + 覆盖 + 血缘 + 哈希链
  bet.yaml          盲下注概率，时间戳必须早于 panel.parquet
  panel.parquet     测量层全部数值，含逐观测 Ψᵢ（下游输入，不只给人看）
  panel.ipynb       全部图
  blades.json       四把刀结果 + 各条 e 值 + 森林入选频率 + 确认段读取审计
  verdict.json      三态判定 + 逐条断言判定 + 赌本 W

```

全局文件见 `PSEUDOCODE.md` 附录 C，其中三个值得单独提：**`chain.log`**（档案哈希链，改任何一份历史档案都会让其后全部校验失败）、**`audit.log`**（确认段与封存段的读取日志）、**`wealth.json`**（全库赌本轨迹）。

## 七、四条纪律

**一 · 顺序决定性质。** 同一句机制解释，写在看到收益数据之前是科学，写在之后是编故事。两者形式上一模一样。所以机制必须冻结并哈希，之后只能被检验、不能被修改。要改就开新 ID。

**二 · 信息防火墙。** 提出假设的岗位不能看到任何收益读数。

**三 · 免费的与花钱的分开。** 不接触未来收益的操作免费，可以放开做（列想法、写断言、算覆盖重叠、构造效度）；接触收益的消耗证据额度。**系统必须在代码层面能区分这两类。**

**四 · 研究层与交易层单向。** 研究层不给价位，交易层不改逻辑。

正式判定使用冻结候选批次的统计检验和 Holm 全库错误控制；e-process 与盲下注赌本首版只作为实验性研究记录。A 段内部重复切分全部是训练/验证折，正式 B 段在候选批次冻结后只读取一次。价格走势的 regime shift 单独记录为时间状态，不把跨阶段不显著直接解释为机制失败。指数成分变化只定义为月末快照观察事件，不能解释为准确的纳入/剔除生效日或公告日。

CPU 密集任务通过受控进程池并行，I/O 通过异步组件处理；任务结果按固定 ID 合并，任何子任务异常都会使批次失效。GPU 接入只替换可插拔的森林或张量计算组件，不改变数据隔离和统计判定协议。

## 八、诚实的限制

这一节必须写进报告，不是掩盖。

**交互效应在全 panel 上几乎不可能被检出。** 交互检验问的是"两个子组的效应是否不同"，那是一个差值，方差要翻倍：门槛是 $5.6/\sqrt{n_{\text{eff}}'}$，而不是主效应的 $2.8/\sqrt{n_{\text{eff}}}$。

| 探索段占比 | 确认段 n_eff | 可检出的最小交互 | 对比主效应 ≈0.05 |
|---|---|---|---|
| 0.65 | 1510 | **0.144** | 2.9× |
| 0.50 | 2210 | **0.119** | 2.4× |

**这不是方法问题，是数据问题。** 四条缓解，按有效性排序：

1. **优先做事件格。** 事件样本的横截面相关远低于全 panel，有效样本量可能高一个量级。**交易约束、被动资金、不确定性这三行几乎全是事件格，它们是功效上的退路。**
2. 候选先由 `friction` 标签收窄到 3–5 个——不改变单次门槛，但大幅减少检验次数。
3. 探索段占比降到 0.5 甚至 0.35。
4. **接受 UNDECIDABLE 是常态**，写重开条件等数据积累。

**如果算出来交互门槛远大于主效应（大概率）**：不要降低阈值硬找方向。正确的反应是把研究重心从"找调节变量"移到"找主效应"和"做事件研究"，并明确说明这个数据量下发现层能做到什么、不能做到什么。**这本身就是一个诚实且有价值的结论，而且是绝大多数同类工作不会报告的。**

其余已知风险共 18 条，见 `PSEUDOCODE.md` 附录 D。严重度最高的四条：复权方向搞反、忽略 T+1 建仓、层次模型欠识别、确认侧功效不足。

## 九、验收标准

> 成功标准**不是**"找到 N 个 PASS 的结构"。
>
> 是"`law.md` 里有一批**被明确证伪**的机制假设，和一小批（很可能是 1–3 个）在成本口径下、有效样本量充足时站得住的结构"。

外加三个可以报出的数字，每一个都是同类工作不会报的：

1. **全库赌本轨迹** —— 我们一共积累了多少证据、花掉了多少额度
2. **盲下注校准曲线** —— 我们的机制陈述有多可预测（即可解释性的量化）
3. **UNDECIDABLE 占比** —— 我们承认有多少问题这份数据回答不了

| 阶段 | 内容 | 为什么先做 | 预估 |
|---|---|---|---|

## 十一、代码结构

```
engine/config.py    显式日期、成本和数据配置
engine/data.py      PyArrow 分区读取、状态连接、PIT 复权、数据质量闸门
engine/factors.py   已登记的日频量价因子
engine/metrics.py   IC、TB、HAC t、regime 和影响分解
engine/pipeline.py  结构化 JSON/Parquet 产出
run_engine.py       真实研究入口
src/schema.ts       前端与 Python 产物共享的 TypeScript 契约
```

所有组件通过显式输入输出连接；策略、成本、数据校验和后续森林/层次模型可以替换。Python 是唯一研究引擎，TypeScript 不承担数据或统计计算。

当前后端由 Python `engine/` 负责：数据校验、PIT 状态和复权、注册因子、IC/TB/HAC、影响分解、结构化 JSON/Parquet 产出。TypeScript `src/schema.ts` 只定义前后端共享契约，未来前端直接消费引擎产物。真实引擎默认拒绝未经核验的口径，不会用合成数据结果替代真实结论。

运行方式：`python run_engine.py --data-root D:\\finance_agent\\data --output-root artifacts`。正式运行会读取真实 Parquet；复权方向、状态表、PIT 行业任一校验失败都会终止。当前单结构命令只负责真实测量和产出，B/H 正式确认、森林和层次模型在各自依赖通过统计验收后接入，不会把未实现部分伪装成 PASS。
