# 异质性驱动的假设进化

基础格子是机制构件的起点，不要求每个构件单独成为 alpha。研究流程是：
训练段发现条件结构与方向 → 冻结新机制假设 → 模型审查 →
测量子代并比较父代/供体 → 继续有界进化 → 独立确认。

## 当前实现

- `engine/discovery.py` 保留 honest 浅树的完整叶路径。每条路径由冻结切点构成，
  可包含多个变量；训练期叶效应可以为正或负。路径至少出现在一半树中，
  最多保留八条。这是探索频率门槛，不是显著性或因果识别证明。
- 后续重复切分的验证结果不选择路径。传入进化器的路径和方向只来自第一个
  训练切分；逐折 p 值另外作为诊断。原单变量 ICM 诊断不冒充整条路径的确认。
- 单变量分流只读取带隔离带的 A 训练前缀；条件切点也在该前缀冻结。
  分流只是诊断，不能过滤森林候选：纯交互可能没有任何边际均值差异。
  森林保留全部可用的冻结候选（最多五个），允许搜索这种联合结构。
- `engine/evolution.py` 同时报告有符号及绝对 IC/原始分组价差、双侧训练检验、
  后段方向表现。IC 与价差两路反向候选各用 .025 门槛；这仍不是搜索总体校正。
  正反方向分别重新排序并扣除固定成本，绝不把原净收益直接取负。
- 安慰剂统计改用绝对平均 IC 的双侧尾部；负向关系不再仅因符号被拒绝。
  完整时间替代零假设的真实数据校准仍须另行完成，fast 始终不授予正式通过。
- 有条件线索时，整体均值弱、主效应功效不足或父代安慰剂未通过，不阻止生成
  明确标记为探索性的条件子代。父代失败记录保留，不改写为机制法则。
- 子代包括完整路径条件化、反向假设，以及不同异质性构件的信号乘积。
  交互组合的供体不要求单独 PASS，但须有训练条件线索且周期一致。
  模型必须解释并审查**实际冻结的组合表达式**，不能另选效果更好的表达式。
- 每次最多四个后续假设，谱系深度最多二；四个冷启动之后优先推进子代，
  每四次保留一次种子探索。有限预算不再为穷尽 70 格而挤掉所有子代。
- 组合的地图坐标仅用于提案路由，祖先通过 parent/donor 记录。真实表示类型和表达式记录在 lineage；
  贝叶斯记忆按真实表示类型建模，不把乘积冒充 F5 背离。
- 报告提供条件路径数、反向候选数、子代数，以及相同日期、相同覆盖下的
  父代和供体消融比较；条件内外差异另列。缺失覆盖保持缺失。

## 证据边界

A 后段已被原框架探索使用，新的子代比较明确标记为 `descriptive_A_reuse`。
它既不是未见样本，也不证明子代比父代优越。真实 alpha 仍须独立确认、
搜索多重性控制、成本与可执行交易验证。复杂度本身不构成证据。

`--full-grid` 是总研究预算入口，默认开启进化与条件发现。
`engine.initial_search` 仍是显式禁止进化的并行初始化工具；
不要把它的网格覆盖报告当成完整进化结果。

## 本次验证

合成的零整体效应、正负联合条件样本检验了真实森林路径提取。
其他回归检验覆盖后段收益不影响训练方向/规则、负信号双侧安慰剂、
反向成本重算、缺失覆盖、冻结组合进入模型审查、父子谱系与调度。
这些证明实现行为，不能替代真实数据中的机制有效性验证。
