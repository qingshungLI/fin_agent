模板原始副本保留在 assets/template-swiss.html，上游许可原文保留在 assets/GUIZANG-LICENSE.txt。assets/motion.min.js 来自该 skill 的捆绑资源，保留其原始头部说明。此说明用于源码归属，不表示上游作者或支持方认可本项目。

PowerPoint 和架构图由项目 Python 脚本单独生成；code.zip 不包含网页演示模板及其第三方运行时。
