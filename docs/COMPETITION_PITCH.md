# AURORA 参赛展示与答辩文案

本文件与 [参赛正文](../competition_submission.md) 配套。展示名称统一为 AURORA Alpha Harness，中文副标题为“可审计的自演化量化研究智能体”。

## 30 秒开场

大家好，我们的项目是 AURORA。我们关注量化研究中一个具体问题：一个信号出现之后，如何追溯它为什么被提出、经过哪些检验，以及应该如何继续研究？AURORA 把机制提案、实验冻结、统计检验和假设演化连成可执行的流程，并通过机制地图和证据报告交付结果。我们希望让研究团队的每一次探索，都留下可复核、可积累的证据。

## 八页 PPT 文案

### 第 1 页：项目定位

**标题：AURORA｜可审计的自演化量化研究智能体**

副标题：让每一次因子探索，都留下可追溯的证据。

视觉：真实机制地图作为主图，展示“假设 → 检验 → 演化 → 证据”四个环节；页脚放团队名称。

### 第 2 页：研究人员需要回答的三个问题

- 这个候选为什么值得测？需要经济机制与可检验断言。
- 当前结果能支持什么？需要完整检验状态与数据边界。
- 下一轮应该研究什么？需要保留失败原因与父子关系。

讲解重点：把产品价值落到研究人员的实际决策。

### 第 3 页：一个可运行的研究闭环

展示机制坐标、角色协同、冻结、测量、证据核对、后续假设、研究记忆。另画独立确认入口，标明它有单独的准入要求。

讲解重点：模型负责参与提出和审查假设；计算模块执行测量与判定。训练段演化结果仍需重新验证。

### 第 4 页：三个关键设计

- 机制地图与受限表达式，让假设有结构、有边界。
- 训练异质性与父子比较，让后续探索有具体依据。
- 冻结、角色字段约束与审计，让研究步骤可追溯。

每项配一张实际界面或一段简短结构化产物，避免纯概念堆叠。

### 第 5 页：真实研究案例

使用归档 C011：训练段发现反向线索，后续探索段方向未保持。

展示“训练观察 → 后续证据 → 当前结论”三列。结论写“方向稳定性尚不足，保留证据冲突”。后续 A 段不标作独立确认。

如果补充 Core Lab 条件交互截图，放在单独案例页，并标明其来源、短窗口和训练选择口径，不与归档候选合计。

### 第 6 页：当前交付成果

左侧展示控制台、证据报告、自有数据入口；右侧展示 2026-09-09 归档快照：15 个完成候选，6 个已评估子代，9 个证据不足，6 个未通过，0 个独立确认。

讲解重点：工程能力已有可查看产物，统计有效性继续通过正式检验积累。数据卡片需带快照日期，不能标成实时计数。

### 第 7 页：谁来用，如何验证价值

首批用户：有自有数据的小型量化研究团队与金融工程实验室。

试点流程：接入现有数据 → 完成一条研究流程 → 人工复核报告 → 记录复核时间、合同完整率、恢复表现与成本。

拟议收费：本地部署和技术服务、团队许可、数据适配。将付费意愿与收益改善列为待验证事项。

### 第 8 页：下一阶段

完成正式安慰剂校准与冻结批次独立确认；检查自动条件发现的产出与方向稳定性；开展自有数据试点，验证接入成本和研究效率。

收尾口播：AURORA 已经把研究步骤、证据和后续假设连接起来。我们希望把它发展成团队可持续使用的研究工具，让每一轮实验都能为下一轮提供清晰依据。

## 答辩问答

**为什么现在没有正式确认因子，项目仍然有价值？**

当前交付包括可运行的研究流程、冻结记录、候选评估和演化谱系。它们支持复核和继续研究。归档未完成全部确认环节，所以我们没有把探索结果称为有效 alpha。后续用正式确认和团队试点分别评估研究产出与工具价值。

**自演化具体改变了什么？**

它在既定预算、表达式和深度约束内提出新的研究假设，包括表达形式迁移、条件、方向及交互子代，并比较父子结果。这里的自演化指假设与研究计划的迭代，不涉及自动修改底层模型权重。

**模型会不会看到结果后编故事？**

完整引擎按角色限制上下文字段，提案和盲下注入口不接受原始收益与 B/H 观测；后续演化可以接收获准的训练线索，仍被标作探索假设。结果核对与归纳属于结果产生后的角色，其输出不能充当事前先验。

**用了几个 Agent？**

完整引擎定义了提案、操作化、审查、盲下注、核对和归纳六类角色。它们共享模型，通过不同输入合同分工。自有数据 SDK 则提供不调用外部模型的独立实验路径。

**如何应对反复筛选产生的假阳性？**

项目通过冻结实验、区分探索与确认、限制信息输入，以及独立确认入口中的批次校正等措施约束研究流程。具体结论需要满足各项检验前提；实验性 e 轨迹不参与正式判定，因此不将它作为整个系统可任意顺序查看的保证。

**三维地图对研究有什么帮助？**

它用于定位研究覆盖和父子关系，便于展示及导航；具体结论由证据详情和报告支持。二维地图也能完成坐标选择与审查。

**现在可以直接卖给机构吗？**

当前可以交付源码并进行本地试点。正式团队产品还需要根据客户环境补齐权限、运维、数据接入与服务保障；商业计划首先验证接入成本和复核效率。
